# عزيز للتقنيات — بوابة الدعم الفني
نموذج أولي باستخدام Flask وPostgreSQL. المستخدم يرى طلباته فقط؛ حساب المهندس يرى جميع الطلبات ويحدّث الحالة.

## تنبيه أمني
هذا نموذج أولي غير مدقق أمنيًا وليس جاهزًا لاستقبال بيانات حقيقية. يلزم اختبار النشر، سياسة خصوصية، استعادة الحساب، النسخ الاحتياطي ومراجعة أمنية. لا تضع كلمات المرور أو المفاتيح في GitHub.

## متغيرات بيئة Render
- `SECRET_KEY`: قيمة سرية يولدها Render.
- `ENGINEER_EMAIL`: بريد المهندس.
- `ENGINEER_PASSWORD`: كلمة مرور فريدة بطول 16 حرفًا على الأقل.
- `DATABASE_URL`: اتصال PostgreSQL الذي يوفره Render.

لتجربة محلية: `pip install -r requirements.txt` ثم `python app.py`.
